# Changelog

Все значимые изменения проекта OSS Hub.

---

## Даже писать стыдно: Выпил ссылок на релизы и хардкода админа
- **Безопасность**: админка теперь проверяется строго по таблице `admins` в базе данных Turso.
- **Права доступа**: вырезан весь хардкод логина администратора из роутов, CRM и действий модерации.
- **Изоляция CRM**: даже администратор платформы больше не имеет доступа в CRM чужих проектов.
- **Интерфейс чейнджлога**: убраны даты и семантические цифры, удалены внешние ссылки на релизы, введена шкала апдейтов («Важный апдейт», «Минорный апдейт», «Микрофикс», «Даже писать стыдно»).

---

## Микрофикс: Починили статус отклонённых и снятых задач
- **Клеймы**: статус `rejected` больше не блокирует задачу.
- **Интерфейс карточки**: задача возвращается в состояние «Свободна» с зелёной кнопкой взятия.
- **Самоотзыв**: добавлена кнопка «Снять заявку» в диалоговом треде задачи для исполнителя.

---

## Важный апдейт: Полноэкранный воркспейс Maintainer CRM и база знаний
- **Maintainer CRM**: канбан-воронка заявок, живой тред диалога, бэклог задач, роли в команду, ростер участников, онбординг.
- **Руководство**: интерактивный раздел `/guide` для контрибьюторов и авторов с FAQ.

---

## Минорный апдейт: Центр контрибуции и комплекс защиты
- **Fast-Track Hub**: автоматическая синхронизация GitHub Issues с определением сложности, взятие задач через клеймы, прикрепление PR, 1-liner запуск.
- **Безопасность**: скользящий rate limiting, санитизация Markdown через DOMPurify, защита от SSRF, эндпоинты безопасности.

---

## Важный апдейт: Публичный релиз платформы OSS Hub
- Каталог репозиториев, авторизация через GitHub OAuth, профили разработчиков, база Turso, тёмная инженерная дизайн-система.
