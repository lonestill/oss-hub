# Changelog

Все значимые изменения проекта OSS Hub фиксируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/), проект придерживается [Семантического Версионирования](https://semver.org/lang/ru/).

---

## [1.2.0] — 2026-10-10

### Добавлено
- **Полноэкранный воркспейс Maintainer CRM (`/projects/[slug]/crm`)**:
  - Канбан-доска воронки контрибьюторов с 4 колонками: «Новые заявки», «В разработке», «PR на ревью», «Завершено / В команде».
  - Live Drawer: встроенный приватный тред переписки мейнтейнера с исполнителем прямо на платформе.
  - Управление бэклогом ручных задач (добавление, удаление, сложность, теги, оценка времени).
  - Управление вакансиями и ролями в команду с указанием коммитмента (часов в неделю).
  - Ростер участников: подтверждённая база контрибьюторов и участников команды.
  - Настройка Fast-Track онбординга: 1-Liner Quickstart команда, Architecture Map, шаблон `.env`.
- **Интерактивное руководство платформы (`/guide`)**:
  - Раздел для контрибьюторов: взятие задач, онбординг, отправка PR.
  - Раздел для мейнтейнеров: ведение CRM, воронка кандидатов, онбординг команды.
  - FAQ и архитектурный манифест проекта.
- **Публичная страница истории версий (`/changelog`)**:
  - Хронология релизов с категоризацией изменений, бейджами версий и статистикой.

### Исправлено
- **Логика освобождения задач (Task Claims)**:
  - Устранена блокировка карточки задачи при статусе клейма `rejected`: отклонённые и отменённые заявки больше не считаются активными.
  - Задача гарантированно возвращается в состояние «Свободна» с зелёным индикатором и кнопкой «Взять задачу прямо на сайте».
  - Добавлена возможность для контрибьютора самостоятельно отозвать свою заявку («Снять заявку») в диалоговом треде.
  - На сервере обновлены права доступа: автор клейма может безопасно отзывать свою заявку без ошибки 403 Forbidden.

## [1.1.0] — 2026-10-09

### Добавлено
- **Центр контрибуции и Fast-Track Hub**:
  - Автоматическая синхронизация GitHub Issues с разметкой сложности (`good first issue`, `help wanted`, `architecture`).
  - Система прямого взятия задач с питчем решения в обход внешних тредов.
  - Привязка GitHub PR к взятой задаче и отображение статуса проверки.
  - Подача заявок на вакансии в команду (роли, опыт, контакты).
- **Комплекс защиты и безопасности**:
  - In-memory скользящий Rate Limiting (`EdgeRateLimiter`) для защиты от флуда и DoS на комментариях, заявках и авторизации.
  - Санитизация Markdown через `DOMPurify` во вьюере README и описаний.
  - Защита от SSRF в GitHub API парсере (валидация домена `api.github.com`, блокировка локальных IP 127.0.0.1, 169.254.169.254).
  - Защитные HTTP-заголовки безопасности в `next.config.ts`.
  - Эндпоинты `/.well-known/security.txt`, `/robots.txt` и `/flag.txt` для исследователей безопасности.

### Изменено
- **Зачистка секретов и конфигурации**:
  - Полностью исключены чувствительные токены и пароли из кодовой базы.
  - Добавлен эталонный шаблон окружения `.env.example`.
  - Репозиторий очищен и форс-пушнут в публичный доступ GitHub: `https://github.com/lonestill/oss-hub`.

## [1.0.0] — 2026-10-09

### Добавлено
- **Первый публичный релиз платформы OSS Hub**:
  - Каталог открытых проектов с фильтрацией по языкам программирования и тегам поиска контрибьюторов.
  - Авторизация через GitHub OAuth с HMAC-SHA256 сессионными куками.
  - Профиль разработчика (`/users/[username]`): опубликованные репозитории, задачи в работе, заявки в команды и суммарные звёзды.
  - Добавление проектов через прямую ссылку или выбор из репозиториев пользователя GitHub.
  - База данных Turso / libSQL с автоматическими миграциями схемы.
  - Тёмная инженерная дизайн-система в стилистике GitHub / Radix с нулевым использованием эмодзи.
